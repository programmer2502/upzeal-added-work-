How should I structure the Redis keys for a sliding window?

For a sliding window, a Sorted Set is optimal. Use the timestamp as the score. Here is a blueprint:

redis_limiter.ts
const key = \`rate:\${ip}\`;
const now = Date.now();
const windowStart = now - 60000;

await redis.multi()
    .zremrangebyscore(key, 0, windowStart)
    .zadd(key, now, now.toString())
    .zcard(key)
    .expire(key, 60)
    .exec();

This ensures only requests within the last 60 seconds are counted.
